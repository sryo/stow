# Stow

A native macOS bookmark manager built with Swift and AppKit that attaches to any browser window as a sidebar. Forked from [Arcmark](https://github.com/Geek-1001/arcmark).

## Features

- **Browser sidebar** - Attaches to Chrome, Arc, Safari, Brave, or any browser window. Also works as a standalone window.
- **Workspaces** - Organize bookmarks into multiple collections with custom window colors.
- **Nested folders** - Drag-and-drop hierarchical folder structures.
- **Inline editing** - Rename folders and links directly in the list.
- **Search & filter** - Quickly find bookmarks across workspaces.
- **Always-on-top mode** - Pin the window to stay visible above all apps.
- **Arc import** - Import pinned tabs and folder structure from Arc browser.
- **Local-first** - All data stored in a single JSON file on disk.
